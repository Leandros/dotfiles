### Bootstrap a new machine

Debian 12+, Ubuntu 22.04+, Fedora 41+, RHEL 9+ and clones (Rocky, Alma,
CentOS Stream), Amazon Linux 2 / 2023 (x86_64, aarch64), macOS (Apple Silicon):

```
curl -fsSLo bootstrap.sh "https://raw.githubusercontent.com/Leandros/dotfiles/refs/heads/master/bootstrap.sh" && \
    chmod +x ./bootstrap.sh && \
    ./bootstrap.sh
```

Test in Docker: `test/bootstrap/run.sh [debian12|ubuntu2204|fedora43|fedora44|fedora45|rocky9|al2|al2023]`
(all categories; `BOOTSTRAP_CATEGORIES= test/bootstrap/run.sh <distro>` for basic only).
Test the category choice: `test/categories/test.sh`.
Test the tmux plugin install: `test/tmux-plugins/test.sh`.
Test markdown backgrounds in nvim hover popups: `test/nvim-markdown-float/test.sh`.
Test nvim Rust indent after comments: `test/nvim-rust-indent/test.sh`.
Test the zsh clipboard (`bin/pbcopy`/`bin/pbpaste` for vi mode `y`/`p` and fzf's CTRL-Y; Wayland, X, tmux): `test/zsh-clipboard/test.sh`.
less key bindings (`.lesskey`, Bone 2: `b`/`s` scroll left/right, `n`/`r` a line, `(`/`)` a page, `?`/`-` next/previous match) are linked to `~/.lesskey` on every machine; less before 582 (AL2) gets them compiled into `~/.less`. Test: `test/lesskey/test.sh [image ...]`.
Console (kmscon, Fedora 45+): `/etc/kmscon/kmscon.conf` from bootstrap (font size, Solarized, PragmataPro where installed, no mouse). kmscon draws a beam cursor over the character under it, so on `TERM=kmscon` zsh, nvim and tmux use an underline in insert mode instead. Test: `test/kmscon-cursor/test.sh`. Left Ctrl and Alt are swapped on the console as in the sessions: `ctrl:swap_lalt_lctl` in localectl's X11 options (bootstrap, `kb --console`); the X login screen gets it too.
Test the sleep hooks: `test/system-sleep/power-button-wake.sh`, `test/system-sleep/vmware-suspend.sh`.
NVIDIA GPU (desktops): `/etc/modprobe.d/nvidia-power.conf` from `modprobe-conf/` (S0ix, video memory saved to `/var/tmp` across suspend), and the driver's `nvidia-suspend`/`nvidia-resume`/`nvidia-hibernate` units enabled where installed; applies after a reboot. Test: `test/nvidia-power/test.sh`.
Sunshine (Fedora desktops) starts from its launcher (systemd user unit); `~/bin/sunshine-session`
picks the capture for sway or X. Do not set `capture`, `encoder` or `adapter_name` in
`~/.config/sunshine/sunshine.conf`. Test: `test/sunshine-session/test.sh`.
Pair a Moonlight client from a terminal (e.g. over ssh): `sunshine-pin <PIN> [name]`; it asks
for the web UI password (user: `SUNSHINE_USER`, default `$USER`). Test: `test/sunshine-pin/test.sh`.
On firewalld machines (Fedora, EL) the desktop setup enables sshd and allows ssh in the `home` zone.
sway is built from <https://github.com/Leandros/sway/tree/v1.12> (1.12 with the custom pointer
acceleration of sway PR #8592: the touchpad curve of X); `sway-session` starts Fedora's sway when
that build does not load. Tests: `test/sway/test.sh`, `test/sway-session/test.sh`.
The sway touchpad scrolls at `scroll_factor 0.1`; bootstrap installs a Firefox autoconfig
(`firefox/`, next to Firefox, no profile touched) that scales Firefox's scrolling and back
swipe to match, only when Firefox starts in sway. Test: `test/firefox-prefs/test.sh`.
ghostty (Fedora desktops, from copr) is installed next to wezterm with wezterm's keys and
colors (`.config/ghostty`, Linux part `ghostty/linux.conf`). Test: `test/ghostty/test.sh`.
Rio config (`.config/rio`, linked on Linux desktops; install Rio by hand): wezterm's keys,
with the Alt+e leader keys as Alt+Shift+key. Test: `test/rio/test.sh`.
Alacritty (both desktops, built with cargo; the default of `$mod+Return`: `term --use wezterm|alacritty` switches, `term --show` prints the choice; test: `test/term/test.sh`) with wezterm's keys and
colors: `.config/alacritty/alacritty.toml` (shared with macOS) and its Linux part
`alacritty/linux.toml`. Copy mode is vi mode (Alt+Shift+Space) with the Bone 2 keys (b r n s);
Alt+Shift+t copies a URL, path or hash (QuickSelect). No tabs or splits. The colors follow the
desktop through `bin/alacritty-theme` (user unit `alacritty-theme.service`). Test:
`test/alacritty/test.sh` (runs Alacritty under Xvfb in docker).
Media keys (volume, mute, screen brightness) are bound in i3 only; check with `test/media-keys/test.sh`.
